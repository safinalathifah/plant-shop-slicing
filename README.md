# Plant Shop E-Commerce - UI Slicing

Hasil *slicing* UI Design dari Behance menjadi tampilan web interaktif dan responsif menggunakan HTML, CSS, dan Vanilla JavaScript.

## Quick Links
- **Live Demo:** [Lihat Website Interaktif](https://safinalathifah.github.io/plant-shop-slicing/)
- **Original UI Design:** [Plant Shop E-commerce di Behance](https://www.behance.net/gallery/206204229/Plant-Shop-E-commerce-Website-Design)

## Tech Stack
* **Markup:** HTML5 (Semantic Elements)
* **Styling:** CSS3 (Flexbox, CSS Grid, Custom Variables, Responsive Media Queries)
* **Scripting:** Vanilla JavaScript (ES6+)
* **Assets:** FontAwesome Icons, Google Fonts (Playfair Display & Poppins)

## Fitur & Interaktivitas
- **Responsive Layout:** Tampilan menyesuaikan perangkat Desktop, Tablet, dan Mobile.
- **Product Filter Tabs:** Filter katalog produk (*What's New*, *Best Sellers*, *Customer Favorites*) secara dinamis menggunakan JS.
- **Cart Counter & Toast Notification:** Feedback visual instan saat pengguna menekan tombol "Add to Cart".
- **Newsletter Subscription Form:** Penanganan input form secara interaktif.

## Slicing Highlight & Accuracy
- Mengimplementasikan *Hero Section Frame Arch* dan *Price Badge Float* presisi sesuai desain Behance.
- Pengujian tata letak menggunakan ekstensi *PerfectPixel* untuk memastikan akurasi visual.
